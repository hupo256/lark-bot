# falive 接管：出错 → 规则或闸（沉淀台账）

> 原则（aven 2026-10-14 同意）：每次 bot 出错，不只修那一次，必须落成**规则**（提示词 / 文档里的硬口径）或**闸**（代码里的机械检查），并写明怎么验。
> 规则管「怎么理解」，闸管「说出口之前查一遍」。只有规则没有闸的，默认再出一次就补闸。
> 新条目追加在最下面；每条四栏：现象 · 根因 · 落在哪（规则 / 闸）· 怎么验。
