## 2. HTTP 通用约定

### 2.1 请求

- Base：`/api/...` 或 `/bbs/...`、`/bbsv2/...`
- GET/DELETE：`channel_code` → query
- POST/PUT：`channel_code` → JSON body（`Content-Type: application/json`）
- FormData：append `channel_code`
- `device_type` 常见 `pc`

### 2.2 Method 含义（官方）

| Doc 标注 | 含义 |
| --- | --- |
| `GET` | 推荐/限定 GET（幂等读） |
| `POST` | 推荐/限定 POST（写） |
| `DELETE` | 删除类 |
| `All` | 多种 HTTP 方法可用；以详情页 `@http_method` 或 action 前缀（如 `getXxx`）为准 |

详情页示例：  
https://streampreadmin.fdsser.com/doc/index/detail?fullClassActionName=app.http.live.ctrl.CLiStre-getRoomInfo

### 2.3 请求头

| Header | 说明 |
| --- | --- |
| `token` | 登录态 |
| `vn-version` | 客户端版本 |
| `X-Site-Platform` | 站点/渠道平台 |
| `vn-visitor` | 游客 ID（无 token 时必需逻辑） |
| `X-Accept-Language` | `vi` / `zh-cn` / `en-us` 等 |
| `vn-channel` / `vn-time` / `vn-sign` | 渠道、时间、签名 |
| `vn-brand` / `vn-model` / `vn-oaid` 等 | 设备指纹 |
| `X-Local-Zone` | 时区 |

本地键：`vn__token`、`vn__v-token`、`vn__uid`、`vn__channel`。  
非法/缺签：`{"msg":"非法请求","code":-800}`。

### 2.4 响应

Web 成功：`code === 0`。敏感字段（mail/mobile/password）前端加密后提交；预发验证码可用 `123456`。

## 3. WebSocket 总览（完整版见专文）

完整字段与官方原文 → [`klivepre-WS完整说明.md`](./klivepre-WS完整说明.md)

### 3.1 连线 / 上行

```
wss://streampre.fdsser.com/wss/?userToken={token}
```

| 上行 | 内容 |
| --- | --- |
| 心跳 | 明文 `heart`（≈10s） |
| 进房 | `{"action":"sub","vid":"..."}` |
| 退房 | `{"action":"unsub","vid":"..."}` |

> 公屏必须先 `sub`；私聊/通知连上即可收。

### 3.2 接收（全部 action）

| 接收 | method | action | 需 sub | 说明 |
| --- | --- | --- | --- | --- |
| 直播间公屏 | `notice` | `send` | 是 | 用户/机器人/管理/表情等 |
| 私聊/群消息 | `noticeUser` | `send` | 否 | 连上即收 |
| 删消息 | `notice` / `noticeUser` | `delmsg` | 视通道 | 房间订阅 vs 按用户 |
| 清屏/清空历史 | `notice` / `noticeUser` | `clearHistory` | 视通道 | 同上 |
| 新消息提醒 | `noticeUser` | `newMsg` | 否 | 会话角标 |
| 加入群组 | `noticeUser` | `newRoom` | 否 | |
| 被踢 | `noticeUser` | `kickuser` | 否 | |
| 关注开播 | `noticeUser` | `startLive` | 否 | |
| 当前房关播 | `noticeAll` | `closeLive` | — | |
| 送礼 | `notice` | `gift` | 是 | |
| 聊天公告 | `noticeChannelsByDay` | `send` | 视配置 | 图文模版 |
| 禁言 | `notice` | `ban` | 是 | |
| 置顶 | `noticeUser` | `pin` | 否 | `pin=1` 置顶 / `2` 取消 |
| 预约开播到点 | `noticeUser` | `reserveStartLive` | 否 | 不论是否有主播在播 |

另有：`noticeIm` / `noticeChannel`、满级进房特效、运营切播、投票定时推送等（见 WS 专文）。

## 4. 业务使用流程

### 4.1 首页冷启动（实测）

1. `GET /api/secret/getHot`
2. `GET /api/live_streaming/tags`
3. `GET /api/banner/getBannerList?banner_type=1&type=1`
4. `GET /api/task/list` → `GET /api/task/show?code=checkin`
5. `GET /api/anchor/sort`
6. `GET /api/LiStre/getRoomInfo?uid=&videoType=m3u8`
7. `GET /api/prompt_map/getPMList`
8. `GET /api/chat/history?vid=&anchorId=&last_id=0&limit=50&room_type=0`
9. iframe：`klive-if-pre` + m3u8；WS `sub`

### 4.2 注册登录

- 发码 `POST /api/user/sendVerificationCode`
- 邮箱注册 `POST /api/user/NewRegisteredByMail` / 手机 `POST /api/user/NewRegistered`
- 登录 `POST /api/user/NewMailLogin` / `POST /api/user/NewLogin`
- 退出 `POST /api/Member/SignOut`；资料 `GET /api/Member/info`

### 4.3 观看直播

`getRoomInfo` → 播放器 → `chat/history` → WS `sub` → 收 `notice/send|gift` 等。

### 4.4 预约 / 签到 / 头条

- 预约：`POST /api/live/reserveMatch2`；列表 `live_streaming/get*Reserve*`
- 签到：`task/list` → `task/show` → `POST task/update`
- 头条：`Headlines/getList` / `getInfo`

### 4.5 主播开播（LIVE_API）

`Member/info(is_anchor)` → `live/getRoomList` → `getLiveUrl` → `localUpload` → `createRoom` → `startRoom` → `endRoom`。

## 7. 联调注意

1. 缺签名头 → `code=-800`；用浏览器 Network 或 Doc 试调。  
2. 路径大小写：`LiStre` / `li_stre` 等以实测为准。  
3. Web 成功码按 `0`；Doc 示例偶见 `1`。  
4. `pull` 带时效签名，过期重新 `getRoomInfo`。  
5. **所有 Method+说明** → 全量清单；**所有 WS 接收** → WS 专文。
