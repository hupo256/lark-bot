## 一、后端（live php）

### Bug-4937 个人主页》勋章页面需要去掉（同根因 Bug-5048）

- **描述**：个人主页》勋章页面打开报错。测试：Kaiser。
- **原因**：pre 上没有勋章接口。`GET /bbs/member/medals?isExpire=0&page=1&pageSize=100` 返回 HTTP 404「404 No Router」；`/bbsv2/member/medals`、`/api/member/medals` 也都是 404。
- **为什么前端不处理**：
  - 前端请求与 x9 完全一致（同一路径、同一参数），没有可改的地方。
  - 前端不能编造勋章数据。
  - 「去掉勋章页」是产品决定，不是 bug 修复。团队规则是接口没通不隐藏功能，见第二节。
- **需要后端**：在 pre 提供 `/bbs/member/medals`，字段同 x9 `memberMedalListSchema`（`data.list[]`）。上线后前端不用改。
