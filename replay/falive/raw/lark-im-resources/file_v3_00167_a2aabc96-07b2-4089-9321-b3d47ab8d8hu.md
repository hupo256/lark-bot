## 推薦直播

### 1. 推薦的視頻（營銷上傳視頻）

**API 列表：**
- `GET /b2b/liveList` - 查詢直播/視頻列表
- `GET /b2b/highlight/{b2bUid}/url` - 取得精彩時刻播放網址
- `GET /b2b/recordVideoList/{streamHostMemberId}` - 查詢錄播列表

#### GET /b2b/liveList
查詢直播列表，支援篩選精彩時刻（liveListType=2）

**Request：**
```
GET /b2b/liveList?pageNum=1&type=4
Header: X-Device-Type
```

| 參數 | 類型 | 必填 | 說明 |
|------|------|------|------|
| pageNum | Integer | 否 | 頁碼，預設 1 |
| searchKey | String | 否 | 標題關鍵字 |
| type | Integer | 否 | 直播類型：-1=全部, 0=足球, 1=籃球, 2=其他, 4=區塊鏈 |

**Response：** `CommonPage<B2BLiveVo>`
```json
{
  "pageNum": 1,
  "pageSize": 20,
  "total": 100,
  "list": [
    {
      "liveId": 123,
      "uid": 456,
      "groupId": 101,
      "groupLink": "https://...",
      "liveListType": 2,
      "isLive": 1,
      "title": "精彩時刻標題",
      "thumb": "https://...",
      "avatar": "https://...",
      "userNickname": "主播暱稱"
    }
  ]
}
```

**說明：**
- `liveListType`: 1=預約節目, 2=精彩時刻, 3=直播中
- 只回傳有推廣群的主播或精彩時刻類型
- 支援快取（1分鐘）

#### GET /b2b/highlight/{b2bUid}/url
取得精彩時刻的播放網址

**Request：**
```
GET /b2b/highlight/123/url
```

**Response：** `LiveStreamVo`
```json
{
  "pull": "https://stream.example.com/video.m3u8",
  "vid": "video_id_123"
}
```

#### GET /b2b/recordVideoList/{streamHostMemberId}
查詢指定主播的錄播列表

**Request：**
```
GET /b2b/recordVideoList/789?pageNum=1
```

**Response：** `CommonPage<B2BRecordVideoVo>`
```json
{
  "pageNum": 1,
  "pageSize": 20,
  "total": 50,
  "list": [
    {
      "id": 123,
      "liveId": 456,
      "title": "錄播標題",
      "thumb": "https://...",
      "duration": 3600,
      "createTime": "2024-01-01 10:00:00"
    }
  ]
}
```

### 11. FameEx 入口

**API 列表：**
- `GET /fameEx/oneTimeToken/v2` - 產生一次性登入 token
- `POST /fameEx/redirect/{action}` - 取得 FameEx 跳轉資訊

**流程：**
1. 產生一次性 token

3. 前端跳轉至 FameEx（自動登入）

#### GET /fameEx/oneTimeToken/v2
產生一次性登入 token

**Response：**
```json
{
  "code": 200,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "expiresIn": 300
  }
}
```

#### POST /fameEx/redirect/{action}
取得 FameEx 跳轉資訊

**Request：**
```
POST /fameEx/redirect/home
```

| action 可選值 | 說明 |
|---------------|------|
| home | FameEx 首頁 |
| assets | 資產頁 |
| recharge | 充值頁 |
| copyTrading | 跟單頁 |
| swap | 交易頁 |

**Response：**
```json
{
  "code": 200,
  "data": {
    "url": "https://fameex.com?token=xxx&redirect=home",
    "method": "GET"
  }
}
```

**說明：**
- token 有效期 5 分鐘，僅能使用一次
- 跳轉後 FameEx 自動完成登入

## 通用說明

### 認證方式
所有接口需在 Header 帶入 JWT token：
```
Authorization: hiApp{your_jwt_token}
```

### 時間格式
統一使用：`yyyy-MM-dd HH:mm:ss`

### 回傳格式
所有接口統一回傳 `CommonResult<T>`：
```json
{
  "code": 200,
  "message": "success",
  "data": { ... }
}
```

### 錯誤處理
- `code=200`：成功
- `code=401`：未登入或 token 過期
- `code=403`：權限不足
- `code=400`：參數錯誤
- `code=500`：伺服器錯誤

### null 欄位處理
回傳 JSON 中，值為 null 的欄位不會出現（Jackson NON_NULL 設定）
