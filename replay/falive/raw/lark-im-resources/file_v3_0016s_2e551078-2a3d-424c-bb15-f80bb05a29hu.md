## 前端约定的返回格式（同 x9，不变就不用改前端）

```json
{
  "code": 0,
  "data": {
    "hot_match": [
      { "sourceid": 1, "short_name_zh": "BTC" },
      { "sourceid": 2, "short_name_zh": "ETH" }
    ]
  }
}
```

- `short_name_zh`：必填，点击后用它去搜索；空字符串会被丢掉，重复的去重。
- `sourceid`：可选。
- `hot_match` 为空或接口失败时，热门搜索整段不显示，不影响历史记录和搜索。
