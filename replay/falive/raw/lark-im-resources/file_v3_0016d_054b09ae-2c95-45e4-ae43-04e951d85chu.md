## 四、请前端特别注意

1. **不要**再调 `/api/new_schedule/*`、内部 `hi_chat_program`。  
2. **upcoming / robotManualList / preload** 须带**渠道**（Header / 约定参数）；无渠道会空列表。  
3. Debug 环境跳过验签：Cookie `_is_debug_skip_sign_limit_for_b2b` = 当天日期（两位）。  
4. 拉流复测：先确认 CDN / referer，再看签名是否仍报过期。
