## P0：登录打通（web 用 live 登录，怎么拿到 hichat 身份）

现状：web 登录走 live（php）的 `/api/user/NewLogin` / `NewMailLogin`，拿到的是 live 的 `data.token`。任务中心等 hichat 接口需要 hichat 的 JWT。我们需要知道下面 4 件事：

| # | 问题 | 前端需要的答案形态 |
|---|---|---|
| H1 | live 用户 id 和 hichat member id 怎么对应？ | 一句话：同一个 id / 有映射表 / 首次访问时自动建号 |
| H2 | 登录后 web 怎么拿到 hichat JWT？ | 接口路径 + 入参（是否用 live token 换）+ 返回示例 |
| H3 | JWT 过期时间、怎么续期，失效时返回什么错误码 | 过期秒数 + 续期接口 + 错误码 |
| H4 | 退出登录时 hichat 侧要不要调接口 | 有 / 没有 |

> 只要 H1、H2 有答复，前端就能开始接；H3、H4 可以后补。
>
> **10-12 观察**：pre 上 live 登录已实测成功，但 `NewMailLogin` 响应日志里 `app\job\live\JHiChatAccountSync::fire` 有 error，并提示「任务重新入队」。请确认：这是不是登录时给 hichat 同步建号（H1），失败原因是什么，同步成功后 web 怎么拿 JWT（H2）。
